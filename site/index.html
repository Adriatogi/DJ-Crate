Yo! This is DJ Crate.

An app to download your music and get it ready for DJing.

Download for Mac

macOS 13+ · Apple Silicon · Free & open source

What it does

Spotify playlists become crates

So, ideally, you'd have a Spotify playlist that has songs you'd want downloaded. These playlists then become crates in the app, and you can explore them, export them, etc. But, you can also make your own crates, with your own downloads. We're also planning (and I think we already do) to support SoundCloud, and other platforms.

Pick the exact link

Honestly the main reason I made this is because spotdl would always pick the wrong link. So now, we have filters and put you in control. And make it very easy even if you do download the wrong version. (We also tell you if you downloaded a clean version by accident!)

Downloads Rekordbox-ready MP3s

So then after downloading, like we said over there ← you'd export it as an XML that Rekordbox then imports. But, at the end of the day, you'll have 1 folder, with all your songs as mp3. So you can use it for whatever. I should probably add folder export too though.

Cutting

So you can visually add notes to songs and stuff. It's cute, try it out.

Set Setter

You can also build sets with the app. So you don't have to do it in a notes app. Although technically, we are.

Works with Rekordbox

I built this with Rekordbox in mind. But as I develop, we'll support other apps too. Just had to satisfy this Rekordbox monopoly that exists out here.

How it works

  1. Import a Spotify playlist. It becomes a crate with each song's title, artists, album, cover and length.
  2. Pick a link for each song. Paste one, use Find (it highlights the result whose length matches Spotify's and warns about other versions), or Auto-fill.
  3. Download. Each song becomes a tagged Title - Artist.mp3 in one library folder.
  4. Import into Rekordbox and prep. Add notes, Cutting and sets; send crates and sets to Rekordbox as playlists.

Install

  1. Download the latest .zip from GitHub Releases.
  2. Unzip it (double-click in Finder).
  3. Drag DJ Crate.app into Applications.
  4. Open it. The first time, macOS says "Apple could not verify 'DJ Crate' is free of malware…". Click Done.
  5. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to DJ Crate, then enter your password. You only do this once.
  6. If macOS asks for Keychain access (for your Spotify login), click Always Allow. This also happens only once.

Requires macOS 13 or later on an Apple Silicon Mac. Developers and Intel Macs: use the install script in the README, which builds from source.
