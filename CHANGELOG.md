# Changelog

Each `## X.Y.Z` section becomes the notes of that GitHub Release.

## 1.0.0

The first public release.

- **Download and run:** DJ Crate is now a self-contained app for Apple Silicon Macs. Python, ffmpeg and deno are inside it, so nothing else needs installing.
- **Update alerts:** DJ Crate checks GitHub once a day and tells you when a new version is out (Settings → About, where you can also turn it off).
- **Getting started guide** for first launch: library, Spotify, first playlist, links, downloads.
- **Cookies from Chrome** (and other browsers) work reliably: the cookies are read once instead of on every download, and Settings can test them.
- Open source under the GPL-3.0.
- yt-dlp 2026.10.26.
